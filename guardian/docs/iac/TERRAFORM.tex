\section{Overview}
This document outlines the Infrastructure as Code (IaC) design for the Guardian Layer using Terraform / OpenTofu. Declarative modules provision and manage the containerized message brokers, secrets managers, relational stores, and analytical observability engines underpinning the 3-layer urban monitoring platform.

\section{Managed Infrastructure Modules}

\subsection{Streaming Broker Infrastructure}
\begin{itemize}[leftmargin=*,itemsep=2pt]
  \item \textbf{Apache Kafka Cluster (KRaft mode):} 3 broker nodes deployed across isolated network zones.
  \item \textbf{Pre-provisioned Topics:}
    \begin{itemize}
      \item \texttt{telemetry-ingest} (alias \texttt{sensors.raw}): 12 partitions, replication factor 3.
      \item \texttt{telemetry-validated} (alias \texttt{sensors.validated}): 12 partitions, replication factor 3.
      \item \texttt{telemetry-dlq} (alias \texttt{sensors.dlq}): 6 partitions, 30-day retention for post-incident security forensics.
      \item \texttt{devices.metadata}: 3 partitions with a compacted log cleanup policy.
    \end{itemize}
\end{itemize}

\subsection{Security Perimeter \& Vault}
\begin{itemize}[leftmargin=*,itemsep=2pt]
  \item \textbf{HashiCorp Vault HA:} 3-node cluster utilizing Raft integrated storage with auto-unseal capabilities.
  \item \textbf{AppRole Automation:} Declarative provisioning of \texttt{guardian-app}, \texttt{twin-app}, \texttt{brain-app}, and \texttt{rotator} roles with scoped HCL policies.
  \item \textbf{Network Isolation:} Docker bridge networks isolating internal database listeners from public edge ports.
\end{itemize}

\subsection{Persistence and Observability}
\begin{itemize}[leftmargin=*,itemsep=2pt]
  \item \textbf{PostgreSQL 16:} Managed relational instance for structured anomaly verdict tables, indexed temporal partitions, and connection pooling.
  \item \textbf{Elasticsearch 8.15:} 3-node cluster with Index Lifecycle Management (ILM) for 90-day forensic log archiving.
\end{itemize}

\section{State Management \& CI Deployment}
\begin{lstlisting}
terraform init
terraform plan -out=tfplan
terraform apply tfplan
\end{lstlisting}
State files reside in remote object storage with state locking enabled. Credentials and tokens are pulled dynamically from Vault, guaranteeing zero hard-coded secrets in repository sources.
